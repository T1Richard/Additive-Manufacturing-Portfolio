# Project Index

这里不是“项目流水账”，每个案例都回答六个问题：

1. 工程背景是什么？
2. 难点和约束是什么？
3. 我具体负责什么？
4. 我如何拆解问题并设计验证？
5. 项目最终形成了什么工程结果？
6. 这个案例能证明我具备什么能力？
