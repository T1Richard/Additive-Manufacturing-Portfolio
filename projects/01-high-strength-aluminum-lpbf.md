# Project 01 — High-Strength Aluminum LPBF Process Development

> Tags: `LPBF` `High-Strength Aluminum` `DOE` `Heat Treatment` `Mechanical Properties`

## 1. Background

面向高比强度结构件应用，需要建立一套适用于高强铝合金的 LPBF 工艺窗口，并验证打印态与热处理后的致密度、缺陷水平和室温力学性能。项目目标不是得到单个“最好参数”，而是形成具有容错能力、可迁移到实际零件的稳定参数区间。

## 2. Engineering Challenge

高强铝 LPBF 的难点通常同时存在：

- 高反射率和高导热导致熔池稳定性窗口较窄；
- 合金元素烧损、热裂倾向与气孔风险需要同时控制；
- 单一能量密度指标无法覆盖功率、速度、道间距、层厚之间的耦合；
- 小试样最优参数并不一定能直接用于大尺寸或复杂构件；
- 热处理对强塑性匹配影响显著，必须与打印参数联动评价。

## 3. My Role

我负责或深度参与：

- 参数矩阵设计与试验顺序规划；
- 打印过程异常记录与缺陷筛选；
- 致密度 / 金相 / 拉伸结果汇总；
- 热处理前后性能对比；
- 工艺窗口收敛与参数包形成；
- 将试样阶段结果向工程制件条件迁移。

## 4. Approach

### 4.1 Build a Process Map

先基于材料特性与已有经验建立合理参数边界，再使用功率、扫描速度、道间距、层厚等变量构建参数矩阵。体积能量密度仅作为辅助观察量，而不将不同参数组合简单等效。

### 4.2 Screen by Failure Mode

每轮试验不是只看“密度最高的一组”，而是按失效模式分类：

- 能量不足 → 未熔合 / 熔道不连续；
- 能量过高 → 深熔、蒸发、飞溅增加；
- 热输入累积异常 → 边缘翘曲或局部开裂；
- 扫描与铺粉耦合异常 → 局部表面缺陷。

通过失效边界反推出稳定窗口，比直接追单点极值更适合工程应用。

### 4.3 Add Mechanical Verification

对候选参数进行打印态和热处理态性能验证，重点观察：

- 强度水平；
- 塑性是否明显牺牲；
- 不同方向的一致性；
- 批次波动；
- 工艺窗口内部是否存在明显性能梯度。

### 4.4 Scale-up Check

在放大到实际零件前，增加对热积累、扫描面积、支撑刚度、零件方向与残余应力的风险审查，避免“试棒通过、零件失败”。

## 5. Key Engineering Decisions

1. 不使用单一 VED 对参数优劣下结论，而是用它做趋势筛选。
2. 参数选择优先稳定窗口中心，而不是试验中的极限高性能点。
3. 性能异常时同时回看粉末状态、打印日志、风场和热处理，而不是默认归因于功率 / 速度。
4. 将“打印参数”和“热处理制度”作为一个联合工艺链评价。
5. 最终输出参数包时增加适用范围和风险备注，避免被当成所有零件的万能参数。

## 6. Result

项目形成了一套可用于工程验证的高强铝 LPBF 参数窗口，并完成热处理与室温拉伸验证。候选参数能够在强度、塑性、致密度和成形稳定性之间取得可接受平衡。

公开版仅展示结论，不披露完整原始参数和受限性能数值。
