# Project 08 — Additive Manufacturing Project Management

> Tags: `Project Management` `Quotation` `Scheduling` `Capacity` `Customer Interface`

## 1. Background

增材制造项目经理不仅需要懂技术，还要把设备能力、打印周期、后处理、检测、成本和客户交期统一起来。很多项目失败并不是因为不会打印，而是因为需求没冻结、工序漏项、排产冲突或技术风险没有提前暴露。

## 2. Engineering Challenge

- 报价需要同时考虑打印时间、材料、后处理、检测和失败风险；
- 多台设备、多项目并行时容易出现机台争用；
- 打印周期只是总交期的一部分；
- 客户经常在项目中途修改数量、尺寸或检测要求；
- 技术问题与商务承诺需要保持一致，不能只追求“先接单再说”。

## 3. My Role

- 参与项目技术澄清与可制造性评估；
- 估算打印时间、机台占用和交付周期；
- 协助报价逻辑与工艺路线拆分；
- 跟踪打印、热处理、后处理、检测和发货节点；
- 协调销售、工艺、生产、质量与外协资源；
- 对风险、变更和异常进行闭环管理。

## 4. Approach

### 4.1 Break Down the Quote

将报价拆成可解释的成本模块：

`材料 + 设备工时 + 气体 / 辅材 + 热处理 + 去支撑 + 机加工 + 表面处理 + 检测 + 外协 + 风险 + 管理`

这样在客户变更要求时，可以快速判断成本和交期影响。

### 4.2 Estimate Machine Occupancy

打印时间估算不只看模型高度，还要考虑：

- 层厚；
- 每层扫描面积；
- 扫描速度；
- 激光数量 / 策略；
- 换层与铺粉时间；
- 预热和冷却；
- 上下板、清粉和设备准备。

最终把“理论打印时长”转化为“真实机台占用时间”。

### 4.3 Build the Critical Path

典型项目路径：

`技术澄清 → 模型冻结 → 排版 → 打印 → 热处理 → 线切割 → 去支撑 → 机加工 → 表面处理 → 检测 → 发货`

其中外协、热处理和机加工往往比打印本身更容易成为关键路径。

### 4.4 Change Control

客户修改要求时，不只记录“改了什么”，还评估：

- 是否需要重新报价；
- 是否影响参数或成形方向；
- 是否影响已排产设备；
- 是否需要新增检测；
- 是否影响承诺交期。

### 4.5 Risk Dashboard

对项目使用简单状态管理：

- Green：按计划；
- Yellow：存在风险但有恢复方案；
- Red：已影响质量 / 交期，需要升级处理。

## 5. Key Engineering Decisions

- 报价和排产必须基于实际工艺路线，而不是只按零件重量估算；
- 机台占用率需要考虑准备、冷却和周转时间；
- 客户要求未冻结前，不轻易承诺极限交期；
- 技术异常必须尽早转化为项目影响，而不是等到临近发货才上报；
- 项目复盘输出可复用模板，减少下次重复踩坑。

## 6. Result

形成适用于增材制件业务的项目管理思路，将技术评估、打印时间估算、报价、排产、风险和交付节点连接起来，使项目状态能够被工程、销售和管理人员共同理解。

## 7. Deliverables

- 项目报价拆解表；
- 打印时间 / 机台占用估算；
- 项目甘特图与关键路径；
- 风险台账；
- 变更记录；
- 交付检查表；
- 项目复盘。
